# 关于甘露音乐（LG Music）

你好！我是 **甘露音乐（LG Music）**，由独立开发者极星（Pointers）自主开发的聚合音乐播放器。

## 关于应用

甘露音乐由极星（Pointers）自主开发，完全免费且开源。所有版本由作者亲自测试，无任何风险，请放心使用。

应用提供：

- **液态玻璃视觉**：磨砂玻璃 + 折射 + 七彩色散 + 金色边缘流光，紫金黑主题默认开启
- **4 套主题**：紫金黑（默认）/ 自定义（支持玻璃开关与取色）/ 纯白 / 纯黑
- **本地音乐**：添加本地目录自动扫描，支持多种默认排序与自定义拖动排序、按歌名实时搜索、多选管理（仅从列表移除，保留本地文件）
- **歌词**：锁屏 / 浮窗歌词（移动端），无歌词时统一显示应用标识
- **多端支持**：Windows 桌面端（含 Win7 兼容版）与 Android 移动端
