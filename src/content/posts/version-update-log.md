这里记录甘露音乐（LG Music）各版本的更新内容。想看某一版的完整说明，点导航栏「下载」进各发布页即可。

## v1.1.0

1. 品牌更新：应用更名为「甘露音乐（LG Music）」，界面、标题与关于页全部切换为新品牌。Android 端需先卸载旧版本再安装新版；Windows 端更新后设置将重置（启用新数据目录）。
2. 修复移动端本地音乐切歌后歌曲高亮不刷新的问题：之前播放完的歌仍保持高亮、新歌不变色，现在切换歌曲或自动连播时高亮会立即更新。
3. 错误提示的反馈渠道改为「官方群聊或作者本人」：遇到错误时截图，附上具体操作步骤以及「设置-错误日志」的内容反馈即可。
4. 移动端「我的」列表：仅显示试听列表/喜欢列表等系统列表，自建歌单及其创建入口已移除。

## v1.0.1

- Windows 液态玻璃重做：修复「太透」直接看到桌面壁纸的问题——紫金黑舞台底改为不透明深色，不再透到壁纸；玻璃底栏/顶栏质感更真实（磨砂玻璃 + 折射 + 七彩色散 + 金色边缘流光），更有「液态玻璃」观感
- 本地音乐（桌面 + 移动）：只扫描「文件名 + 时长」（不再读取专辑/歌手，也不再加载专辑图），无封面的歌曲统一显示应用标识；新增 4 种默认排序（由旧至新 / 由新至旧 / A→Z / Z→A），可长按进入多选、拖动「≡」把手自定义排序、勾选删除（仅从列表移除，保留本地文件）；修复歌曲编号偶现「…」的问题
- 移动端紫金黑：菜单（侧滑）页配色修复——顶部标题清晰可读、菜单区不再刺眼，整体更协调、阅读更舒适
- 本地音乐搜索（桌面 + 移动）：本地音乐页新增按歌名实时搜索，快速定位歌曲；搜索时排序/管理自动收起
- 稳定性：修复 Win7 兼容版启动即退出的问题，双版本（普通版 / Win7 兼容版）均重新验证

## v1.0.0

- 本地音乐（桌面端 + 移动端）：可添加一个或多个本地音乐目录并自动扫描（支持子文件夹，mp3/flac/ogg/oga/wav/m4a），应用内可重新扫描、调整目录顺序、移除目录（只移除配置，不会删除本地文件），扫描到的歌曲可直接播放、切歌与收藏，同目录 .lrc 歌词自动加载；移动端目录授权在重启后仍然有效
- 液态玻璃与紫金黑主题增强：玻璃折射/色散/流光效果明显加强，紫金黑背景更通透、与纯黑主题差异清晰；新增进度条紫→金渐变、主播放按钮紫金宝石圆、Logo 金色辉光；移动端紫金黑内置紫金舞台光壁纸，底栏/侧栏玻璃加紫金辉光
- 其他：锁屏/浮窗歌词在无歌词时默认显示应用标识；移动端关于页内容与桌面端统一
- Windows 提供普通版与 Win7 兼容版，Android 提供 APK

## v0.9.0-Beta.1

- 液态玻璃界面全新上线：磨砂玻璃 + 折射 + 七彩色散 + 金色边缘流光
- 主题体系重做为 4 套：紫金黑（默认，液态玻璃开启）/ 自定义（可开关玻璃与取色）/ 纯白 / 纯黑
- 界面精简与体积优化：安装包更小，启动更快
- Windows 提供普通版与 Win7 兼容版，Android 提供 APK
