甘露音乐（LG Music）v1.0.1 已正式发布，这一版在视觉质感与本地音乐体验上做了全面升级。

## 本版新内容

- Windows 液态玻璃重做：紫金黑舞台底改为不透明深色，不再透到桌面壁纸；玻璃底栏/顶栏质感更真实（磨砂玻璃 + 折射 + 七彩色散 + 金色边缘流光），更有「液态玻璃」观感
- 本地音乐增强（桌面 + 移动）：只扫描「文件名 + 时长」，扫描更快；无封面的歌曲统一显示应用标识；新增 4 种默认排序（由旧至新 / 由新至旧 / A→Z / Z→A），可长按进入多选、拖动「≡」把手自定义排序、勾选删除（仅从列表移除，保留本地文件）；修复歌曲编号偶现「…」的问题
- 本地音乐按歌名实时搜索（桌面 + 移动）：快速定位歌曲，搜索时排序/管理自动收起
- 移动端紫金黑菜单（侧滑）配色修复：标题清晰可读、菜单区不再刺眼，整体更协调、阅读更舒适
- 稳定性：修复 Win7 兼容版启动即退出的问题，普通版与 Win7 兼容版均重新验证
